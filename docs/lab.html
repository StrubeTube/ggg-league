The sliders

What-if only: re-judge history under a different cap band. The live site always runs the adopted rules ($230 / $160).
Team cap
Lower → tighter market: fire-sale hauls impossible to absorb, more cap jail. Higher → looser: easier star-stacking. Fitted value: $230.
Team floor
Higher → fire sales die: sellers must take real salary back. Lower/off → liquidations return. Fitted value: $160. Waivers never trip it.
Sleeper sync
Pulls league status, draft schedule, and every team's official keepers straight from Sleeper — official keepers override local picks everywhere on the site. This also runs automatically on every page visit; for a full data rebuild (trades, rosters, picks) use Run workflow on GitHub — it also runs itself daily.
